Privacy policy

Updated: October 25, 2026

cleverly-odd-analytics is operated by the Cleverly Odd channel owner for personal channel analysis. It is not offered as a service to the public.

Google data

The tool reads channel-owner video analytics using the YouTube Analytics API and the yt-analytics.readonly scope. It does not request permission to upload, modify, or delete channel content.

Use and storage

Analytics reports are saved on the operator's local computer for performance review. OAuth credentials and tokens are stored outside the source repository with access restricted to the local user. They are not published on this website.

Google user data is not sold, used for advertising, or shared through this website. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and access

The operator may delete local reports and credentials. Access can be revoked in the Google Account permissions settings; local copies must be deleted separately.

This website

These static information pages contain no analytics scripts, sign-in forms, or tracking cookies added by the operator. GitHub Pages, the hosting provider, logs visitor IP addresses for security as described in the GitHub Privacy Statement.

Contact

Use the support email displayed on this app's Google OAuth consent screen.
